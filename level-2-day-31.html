Project Finance Overview

Day 31 mở đầu Week 5 với nền tảng của project finance: cấu trúc SPV, non-recourse financing, risk allocation, và cách structuring một project finance deal. Đây là nền tảng cho toàn bộ Week 5 về project finance fundamentals.

Project finance không chỉ là vay tiền cho dự án. Đó là một cấu trúc cụ thể nơi dự án tự nó là người vay, cash flows là collateral, và risk được allocated cho parties best able to manage it.

Block 1 · 15 phút

Vocabulary & Project Finance Terms

8 thuật ngữ project finance cốt lõi. Mỗi mục có IPA, nghĩa, collocation, ví dụ, ghi chú và native alternative.

project finance

/ˈprɒd.ekt ˈfaɪ.næns/

Tài trợ dự án

Ghi chú: Project finance là cấu trúc tài chính nơi dự án tự nó là người vay, không phải sponsor. Lenders' recourse limited to project assets.
  • Collocation: project finance transaction, project finance structure, project finance deal
  • Example: We've structured this as a project finance transaction through an SPV.
  • Native alternative: project financing, non-recourse financing

SPV (Special Purpose Vehicle)

/ˌes piː ˈviː/

Công ty mục đích đặc biệt

Ghi chú: SPV là công ty riêng biệt được tạo ra cho dự án cụ thể. Isolates project risk từ sponsors' other assets.
  • Collocation: set up an SPV, SPV structure, SPV isolates risk
  • Example: The project is financed through an SPV, which isolates the project risk from the sponsors.
  • Native alternative: special purpose entity (SPE), project company

non-recourse financing

/nɒn rɪˈkːs ˈfaɪ.næns.ɪŋ/

Tài trợ không truy đòi

Ghi chú: Non-recourse financing nghĩa là lenders chỉ có thể go after project assets, không phải sponsors' other assets.
  • Collocation: non-recourse financing, non-recourse loan, non-recourse structure
  • Example: This is non-recourse financing, meaning lenders can only go after the project assets.
  • Native alternative: limited recourse financing, project financing

recourse financing

/rɪˈkɔːs ˈfaɪ.næns.ɪŋ/

Tài trợ có truy đòi

Ghi chú: Recourse financing nghĩa là sponsors có full obligation to repay debt, không chỉ limited to project assets.
  • Collocation: recourse financing, recourse loan, full recourse
  • Example: This is recourse financing, so the sponsors have full obligation to repay the debt.
  • Native alternative: full recourse financing, corporate financing

project sponsor

/ˈprɒdʒ.ekt ˈspɒn.sər/

Nhà tài trợ dự án

Ghi chú: Project sponsors là equity investors who set up the SPV và provide equity capital.
  • Collocation: project sponsors, equity sponsors, sponsor equity
  • Example: The project sponsors are the equity investors who set up the SPV.
  • Native alternative: equity investors, project developers

lender

/ˈlen.dər/

Người cho vay

Ghi chú: Lenders là banks or financial institutions who provide debt financing to the project.
  • Collocation: lenders provide financing, lenders' recourse, project lenders
  • Example: The lenders provide debt financing to the SPV.
  • Native alternative: debt providers, financing banks

borrower

/ˈbɒr.əʊ.ər/

Người vay

Ghi chú: Trong project finance, borrower là SPV, không phải sponsors. Đây là điểm khác biệt key với corporate finance.
  • Collocation: SPV is the borrower, project borrower, borrower obligation
  • Example: The SPV is the borrower, not the sponsors.
  • Native alternative: debtor, borrowing entity

cash flow

/ˈkæʃ fləʊ/

Dòng tiền

Ghi chú: Cash flow là nguồn repayment chính trong project finance. Lenders rely on project cash flows for debt service.
  • Collocation: project cash flows, cash flow generation, cash flow for debt service
  • Example: The lenders' recourse is limited to the project assets and cash flows.
  • Native alternative: cash flows, project revenues
Block 2 · 20 phút

Phrases & Sentence Patterns

6 mẫu câu project finance cốt lõi. Mỗi mẫu có công thức, ví dụ, substitution drill, common mistake và native alternative.

We've structured this as a project finance transaction...

Công thức: We've structured this as a project finance transaction through + SPV + with + financing type. Dùng để explain project finance structure.
Structure explanation

We've structured this as a project finance transaction through an SPV, with non-recourse financing.

Substitution drill

Thay financing type: with limited recourse / with full recourse / with recourse to sponsors.

Common mistake

Tránh: "The company will borrow money for the project." (No structure) Nên: "We've structured this as a project finance transaction..."

The project is financed through an SPV...

Công thức: The project is financed through an SPV, which + isolates risk / limits recourse. Dùng để explain SPV purpose.
SPV purpose

The project is financed through an SPV, which isolates the project risk from the sponsors.

Substitution drill

Thay purpose: which limits lenders' recourse / which protects sponsors' other assets / which isolates project risk.

Common mistake

Tránh: "The SPV borrows money." (No purpose) Nên: "The project is financed through an SPV, which isolates risk."

The lenders' recourse is limited to...

Công thức: The lenders' recourse is limited to + project assets and cash flows. Dùng để explain non-recourse feature.
Non-recourse explanation

The lenders' recourse is limited to the project assets and cash flows.

Substitution drill

Thay recourse scope: limited to project revenues / limited to project assets only / limited to cash flows.

Common mistake

Tránh: "Lenders can only get the project." (Vague) Nên: "The lenders' recourse is limited to the project assets and cash flows."

The sponsors have no further obligation...

Công thức: The sponsors have no further obligation to repay the debt if + condition. Dùng để explain sponsor protection.
Sponsor protection

The sponsors have no further obligation to repay the debt if the project fails.

Substitution drill

Thay condition: if the project defaults / if cash flows are insufficient / if the project fails.

Common mistake

Tránh: "Sponsors don't have to pay." (Informal) Nên: "The sponsors have no further obligation to repay the debt."

Risk is allocated to the parties best able to manage it...

Công thức: Risk is allocated to the parties best able to manage + each risk / specific risks. Dùng để explain risk allocation principle.
Risk allocation principle

Risk is allocated to the parties best able to manage each risk.

Substitution drill

Thay risk type: construction risk is allocated to the EPC contractor / market risk is allocated to the off-taker.

Common mistake

Tránh: "The contractor bears the risk." (No principle) Nên: "Risk is allocated to the parties best able to manage it."

The project generates sufficient cash flow...

Công thức: The project generates sufficient cash flow to + service the debt / repay the loan. Dùng để explain debt service capability.
Debt service capability

The project generates sufficient cash flow to service the debt.

Substitution drill

Thay purpose: to service the debt / to repay the loan / to cover debt service.

Common mistake

Tránh: "The project makes enough money." (Informal) Nên: "The project generates sufficient cash flow to service the debt."

Block 3 · 20 phút

Listening · Project Finance Structure Explanation

Nghe một bài giải thích project finance structure mẫu. Đây là mô hình để bạn thực hành explain project finance.

Nhiệm vụ nghe 20 phút

  1. Nghe toàn bộ 1 lần để nắm project finance structure overview.
  2. Nghe lần hai để nhận diện các patterns: SPV structure, non-recourse financing, risk allocation, cash flow.
  3. Nghe lần ba để phân tích structure explanation techniques: structure overview, risk allocation, non-recourse features.
  4. Làm comprehension questions và đối chiếu đáp án mẫu.
  5. Shadowing 3 câu trọng tâm (SPV structure, non-recourse, risk allocation).

Transcript

[Structure Overview]
Good morning. I'd like to explain the project finance structure for this project. We've structured this as a project finance transaction through an SPV, with non-recourse financing.

[SPV Purpose]
The project is financed through an SPV, which isolates the project risk from the sponsors.

[Non-Recourse Feature]
The lenders' recourse is limited to the project assets and cash flows. The sponsors have no further obligation to repay the debt if the project fails.

[Risk Allocation]
Risk is allocated to the parties best able to manage each risk. For example, construction risk is allocated to the EPC contractor through a fixed-price contract. Market risk is allocated to the off-taker through a take-or-pay agreement.

[Cash Flow]
The project generates sufficient cash flow to service the debt. This structure protects the sponsors while providing lenders with security through the project assets and cash flows.

Comprehension Questions

  • Q1: What is the project finance structure?
  • Q2: What is the purpose of the SPV?
  • Q3: What is the lenders' recourse limited to?
  • Q4: How is risk allocated?
  • Q5: How does the project service the debt?

Sample Answers

1. Project finance transaction through an SPV with non-recourse financing.
2. The SPV isolates the project risk from the sponsors.
3. The lenders' recourse is limited to the project assets and cash flows.
4. Risk is allocated to the parties best able to manage each risk (e.g., construction risk to EPC contractor, market risk to off-taker).
5. The project generates sufficient cash flow to service the debt.

Shadowing Challenge

Shadow 1 · SPV structure

We've structured this as a project finance transaction through an SPV, with non-recourse financing.

Shadow 2 · Non-recourse feature

The lenders' recourse is limited to the project assets and cash flows.

Shadow 3 · Risk allocation

Risk is allocated to the parties best able to manage each risk.

Pronunciation Focus

  • Nhấn vào các từ khóa: project finance, SPV, non-recourse, risk allocation, cash flow.
  • Giọng rõ ràng, tự tin khi explain structure.
  • Pause sau mỗi key point để người nghe tiêu hóa thông tin.
  • Nhấn vào key phrases: "limited to", "no further obligation", "best able to manage".
Block 4 · 20 phút

Speaking · Project Finance Overview

Luyện 3 vòng tăng dần: explain SPV structure → explain risk allocation → full project finance overview. Mục tiêu: tự tin explain một project finance deal.

Round 1 · Explain SPV Structure

Explain SPV structure và purpose. Mục tiêu: clear, concise explanation.

We've structured this as a project finance transaction through an SPV. The project is financed through an SPV, which isolates the project risk from the sponsors. This structure protects the sponsors while providing lenders with security through the project assets.

Round 2 · Explain Risk Allocation

Explain risk allocation principle và examples. Mục tiêu: clear risk allocation explanation.

Risk is allocated to the parties best able to manage each risk. For example, construction risk is allocated to the EPC contractor through a fixed-price contract. Market risk is allocated to the off-taker through a take-or-pay agreement. This ensures each party bears the risk they can best manage.

Round 3 · Full Project Finance Overview

Full project finance overview: structure + risk allocation + non-recourse + cash flow. Mục tiêu: complete, confident explanation.

Good morning. I'd like to explain the project finance structure for this project. We've structured this as a project finance transaction through an SPV, with non-recourse financing. The project is financed through an SPV, which isolates the project risk from the sponsors. The lenders' recourse is limited to the project assets and cash flows. The sponsors have no further obligation to repay the debt if the project fails. Risk is allocated to the parties best able to manage each risk. For example, construction risk is allocated to the EPC contractor through a fixed-price contract. Market risk is allocated to the off-taker through a take-or-pay agreement. The project generates sufficient cash flow to service the debt. This structure protects the sponsors while providing lenders with security through the project assets and cash flows.
