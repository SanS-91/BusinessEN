Financial Modeling Basics

Day 38 là ngày đầu tiên của Week 6, tập trung vào cấu trúc mô hình tài chính: model structure, inputs, calculations, và outputs. Bạn sẽ học cách giải thích cấu trúc financial model một cách rõ ràng và chuyên nghiệp trong 3 phút.

Financial model không phải là bảng tính phức tạp — đó là câu chuyện về dự án được kể bằng số liệu. Người nói giỏi không chỉ đọc số — họ giải thích ý nghĩa và kết nối với quyết định đầu tư.

Block 1 · 15 phút

Vocabulary & Model Terms

8 thuật ngữ financial modeling cốt lõi. Mỗi mục có IPA, nghĩa, collocation, ví dụ, ghi chú và native alternative.

model structure

/ˈmɑːdl ˈstrʌktʃər/

Cấu trúc mô hình

Ghi chú: Model structure là cấu trúc của mô hình tài chính. Thường có 3 phần chính: inputs, calculations, và outputs.
  • Collocation: clear model structure, model structure includes, financial model structure
  • Example: The financial model has a clear structure with three main sections: inputs, calculations, and outputs.
  • Native alternative: model architecture, model framework

inputs

/ˈɪnpʊts/

Đầu vào (giả định)

Ghi chú: Inputs là các giả định đầu vào của mô hình. Đây là những biến số có thể thay đổi để test sensitivity.
  • Collocation: model inputs, key inputs, input assumptions
  • Example: The model inputs include key assumptions like revenue growth, operating margins, and capital expenditure.
  • Native alternative: assumptions, input variables

assumptions

/əˈsʌmpʃnz/

Giả định

Ghi chú: Assumptions là các giả định của mô hình. Phải rõ ràng và có thể thay đổi để test các kịch bản khác nhau.
  • Collocation: key assumptions, underlying assumptions, base case assumptions
  • Example: The key assumptions are clearly stated and can be easily modified for sensitivity analysis.
  • Native alternative: assumptions, key drivers

calculations

/ˌkælkjˈleɪʃnz/

Tính toán

Ghi chú: Calculations là phần tính toán của mô hình, chứa các công thức liên kết inputs với outputs.
  • Collocation: calculations section, financial calculations, model calculations
  • Example: The calculations section contains all the formulas that link inputs to outputs.
  • Native alternative: calculations, formulas

outputs

/ˈaʊtpʊts/

Đầu ra (kết quả)

Ghi chú: Outputs là các kết quả đầu ra của mô hình: IRR, NPV, payback period, cash flow projections.
  • Collocation: key outputs, model outputs, financial outputs
  • Example: The key outputs include IRR, NPV, payback period, and cash flow projections.
  • Native alternative: outputs, results

sensitivity analysis

/ˌsensəˈtvəti əˈnæləsɪs/

Phân tích độ nhạy

Ghi chú: Sensitivity analysis là phân tích độ nhạy — test xem thay đổi trong assumptions ảnh hưởng thế nào đến outputs.
  • Collocation: sensitivity analysis, conduct sensitivity analysis, sensitivity to assumptions
  • Example: We conducted sensitivity analysis to test how changes in key assumptions affect the IRR.
  • Native alternative: sensitivity analysis, what-if analysis

scenario analysis

/səˈnærioʊ əˈnæləsɪs/

Phân tích kịch bản

Ghi chú: Scenario analysis là phân tích các kịch bản khác nhau: base case, upside case, downside case.
  • Collocation: scenario analysis, base case scenario, downside scenario
  • Example: We modeled three scenarios: base case, upside case, and downside case.
  • Native alternative: scenario analysis, scenario planning

base case

/beɪs keɪs/

Kịch bản cơ sở

Ghi chú: Base case là kịch bản cơ sở — kịch bản có khả năng xảy ra cao nhất. Là kịch bản tham chiếu chính.
  • Collocation: base case, base case scenario, base case assumptions
  • Example: In the base case, the project delivers an 18 percent IRR with a 4-year payback period.
  • Native alternative: base case, base scenario
Block 2 · 20 phút

Phrases & Sentence Patterns

6 mẫu câu giúp bạn giải thích cấu trúc financial model: opening, inputs, calculations, outputs, sensitivity, scenarios.

Let me walk you through the model structure...

Công thức: Let me walk you through the model structure + structure overview. Dùng để mở đầu giải thích cấu trúc model.
Opening model structure

Let me walk you through the model structure. The model has three main sections: inputs, calculations, and outputs.

Substitution drill

Thay structure: two main sections / four key sections.

The key inputs include...

Công thức: The key inputs include + list of inputs. Dùng để giải thích các giả định đầu vào.
Explaining inputs

The key inputs include revenue growth assumptions, operating margin assumptions, and capital expenditure assumptions.

Substitution drill

Thay inputs: revenue assumptions, cost assumptions, timing assumptions.

The calculations section contains...

Công thức: The calculations section contains + what it contains. Dùng để giải thích phần tính toán.
Explaining calculations

The calculations section contains all the formulas that link the inputs to the outputs.

Substitution drill

Thay content: financial formulas / projection formulas / valuation formulas.

The key outputs include...

Công thức: The key outputs include + list of outputs. Dùng để giải thích các kết quả đầu ra.
Explaining outputs

The key outputs include IRR, NPV, payback period, and cash flow projections.

Substitution drill

Thay outputs: IRR and NPV / IRR, NPV, and payback / key financial metrics.

We conducted sensitivity analysis to test...

Công thức: We conducted sensitivity analysis to test + what you're testing. Dùng để giải thích phân tích độ nhạy.
Explaining sensitivity

We conducted sensitivity analysis to test how changes in key assumptions affect the IRR.

Substitution drill

Thay what: how revenue changes affect NPV / how cost changes affect returns.

We modeled three scenarios...

Công thức: We modeled three scenarios: + list of scenarios. Dùng để giải thích phân tích kịch bản.
Explaining scenarios

We modeled three scenarios: base case, upside case, and downside case.

Substitution drill

Thay scenarios: base case and downside case / conservative case and aggressive case.

Listening · Financial Model Structure Explanation

Nghe một bài giải thích cấu trúc financial model mẫu 3 phút. Đây là mô hình để bạn tái hiện với model thật của mình.

Nhiệm vụ nghe 20 phút

  1. Nghe toàn bộ 1 lần để nắm cấu trúc bài giải thích.
  2. Nghe lần hai để nhận diện các patterns: model structure, inputs, calculations, outputs, sensitivity, scenarios.
  3. Nghe lần ba để phân tích: mỗi phần có rõ ràng không? Số liệu có được giải thích không?
  4. Làm comprehension questions và đối chiếu đáp án mẫu.
  5. Shadowing 3 câu trọng tâm.

Transcript

[Opening]Let me walk you through the financial model structure. The model has three main sections: inputs, calculations, and outputs.

[Inputs]The key inputs include revenue growth assumptions, operating margin assumptions, and capital expenditure assumptions.

[Calculations]The calculations section contains all the formulas that link the inputs to the outputs.

[Outputs]The key outputs include IRR, NPV, payback period, and cash flow projections.

[Sensitivity]We conducted sensitivity analysis to test how changes in key assumptions affect the IRR.

[Scenarios]We modeled three scenarios: base case, upside case, and downside case. In the base case, the project delivers an 18 percent IRR with a 4-year payback period.

Comprehension Questions

  • Q1: What are the three main sections of the model?
  • Q2: What are the key inputs?
  • Q3: What does the calculations section contain?
  • Q4: What are the key outputs?
  • Q5: What scenarios were modeled?

Sample Answers

1. Three main sections: inputs, calculations, and outputs.
2. Key inputs: revenue growth assumptions, operating margin assumptions, and capital expenditure assumptions.
3. Calculations section contains all the formulas that link inputs to outputs.
4. Key outputs: IRR, NPV, payback period, and cash flow projections.
5. Three scenarios: base case, upside case, and downside case.

Shadowing Challenge

Shadow 1 · Opening

Let me walk you through the model structure. The model has three main sections: inputs, calculations, and outputs.

Shadow 2 · Inputs

The key inputs include revenue growth assumptions, operating margin assumptions, and capital expenditure assumptions.

Shadow 3 · Outputs

The key outputs include IRR, NPV, payback period, and cash flow projections.

Pronunciation Focus

  • Nhấn vào các từ khóa: model structure, inputs, calculations, outputs.
  • Nhấn vào các metrics: IRR, NPV, payback period.
  • Giọng rõ ràng, tự tin khi giải thích cấu trúc.
  • Ngắt rõ giữa các phần: inputs → calculations → outputs.
Block 4 · 20 phút

Speaking · Financial Model Structure 3 Minutes

Luyện 3 vòng tăng dần. Mục tiêu cuối cùng: giải thích cấu trúc financial model trong 3 phút mà không đọc slide.

Round 1 · Model Structure (1 phút)

Giải thích cấu trúc model: opening, inputs, calculations, outputs.

Opening: Let me walk you through the model structure. The model has three main sections: inputs, calculations, and outputs.

Inputs: The key inputs include revenue growth, operating margins, and capital expenditure.

Calculations: The calculations section contains all the formulas linking inputs to outputs.

Outputs: The key outputs include IRR, NPV, payback period, and cash flow projections.

Round 2 · Inputs/Outputs (2 phút)

Mở rộng: thêm chi tiết về inputs và outputs, sensitivity analysis.

Inputs: The key inputs include revenue growth assumptions of 15 percent annually, operating margin assumptions of 25 percent, and capital expenditure assumptions of 100 million dollars.

Outputs: The key outputs include an 18 percent IRR, positive NPV of 42 million dollars, 4-year payback period, and strong cash flow projections.

Sensitivity: We conducted sensitivity analysis to test how changes in revenue growth affect the IRR.

Round 3 · Full Explanation (3 phút)

Hoàn chỉnh: thêm scenarios và kết luận.

Calculations: The calculations section contains all the formulas that link the inputs to the outputs.

Outputs: The key outputs include an 18 percent IRR, positive NPV of 42 million dollars, 4-year payback period, and strong cash flow projections.

Sensitivity: We conducted sensitivity analysis to test how changes in key assumptions affect the IRR.

Scenarios: We modeled three scenarios: base case, upside case, and downside case. In the base case, the project delivers an 18 percent IRR with a 4-year payback period.

Common Mistakes

4 lỗi thường gặp khi giải thích financial model

Tránh các lỗi này để bài giải thích của bạn rõ ràng, chuyên nghiệp và không đọc slide.

Tránh: Đọc nguyên văn chữ trên slide. Người nghe đọc nhanh hơn bạn nói — họ sẽ chán.
Nên: Slide có 3–5 từ khóa. Bạn nói câu chuyện, slide chỉ hỗ trợ. Nhìn khán giả, không nhìn slide.
Tránh: Đọc số mà không giải thích: "IRR is 18 percent." (Rồi sao?)
Nên: IRR is 18 percent, exceeding our 15 percent hurdle by 300 basis points, which means the project creates significant value.
Tránh: Nhảy đột ngột giữa các phần, không có câu chuyển ý.
Nên: Now let me move from the inputs to the calculations section...
Tránh: Kết thúc đột ngột: "That's all. Thanks." Không có kết luận.
Nên: In summary, the model shows strong returns with manageable risk. The key takeaway is that this project creates significant value.
